# Testing

## Unit Tests

[Vitest](https://vitest.dev/) is used for unit testing. The tests are located in the `tests` directory.

## Running Tests

**Unit Tests**

```bash
pnpm run test
```

**Coverage**

  ```bash
  pnpm run test:coverage
  ```
