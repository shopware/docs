:::warning
Single File Component (SFC) support for Administration extensions is **experimental**. It is currently only available on the `trunk` branch of [shopware/shopware](https://github.com/shopware/shopware) and is not part of any 6.7 release. The APIs described on this page can still change without a deprecation. Try it out and tell us what you find, but do not ship an extension built on it to customers or to the Shopware Store until the API is declared stable (planned for 6.9).
:::
